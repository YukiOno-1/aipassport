# 第2章：生成AIモデルの誕生系譜と技術の基礎

***

## 1. 生成モデルの誕生：ボルツマンマシン

### ボルツマンマシン（1985年）

* **ジェフリー・ヒントン**と**テリー・セジュノスキー**の研究グループが提唱

* ニューラルネットワークの一種

* データのパターンや関連性を見つける際に、**確率的に動作**する（完全な答えを1つ出すのではなく、可能性のある答えを多数出して最良を選ぶ）

**「多層学習が可能」とは？**
それまでのニューラルネットワークは1〜2層しか重ねられなかった。ボルツマンマシンの登場で「何層にも積み重ねて学習する（＝多層学習）」ができるようになった。層が増えるほど複雑なパターンを認識できる。

* 下火だったニューラル学習の分野に活気が戻った

* ただし、データ量増加により処理に膨大な時間がかかり、**実用化には未完成**なモデルだった

### 制限付きボルツマンマシン（1986年）

* ボルツマンマシンの問題を改善するために開発

**「接続を制限して入力部分と推定部分に分ける」とは？**
ボルツマンマシンは全ニューロンが全ニューロンと繋がっていたため計算が爆発的に増えた。
→ 「隣の層のニューロンとしか繋いではいけない」というルールで接続数を制限し、
　「データを受け取る入力層」と「パターンを推定する隠れ層」の2つに役割分担させることで処理を高速化した。

* 応用：次元削減、データの分類、データを特徴づける傾向の学習

* **教師あり学習に加え、教師なし学習も可能**になった

## 2. 自己回帰モデルとディープラーニング（1990〜2000年代）

**「回帰」とは？**
「過去に戻って（回って）参照する」という意味。数値の予測に使う手法。
「自己回帰」＝自分自身の過去のデータを参照して次の値を予測すること。
例：「昨日・今日の株価を使って明日の株価を予測する」

| モデル           | 概要                                                                         |
| ------------- | -------------------------------------------------------------------------- |
| **自己回帰モデル**   | 過去のデータから将来を予測する手法。株価・天気など**時系列データ**の予測に特に効果的                               |
| **ディープラーニング** | 人間の脳の働きを模倣した技術で複雑なパターンを学習。2006年に制限付きボルツマンマシンを多段的に重ねたニューラルネットワークが提唱され飛躍的に発展 |

## 3. 主要なニューラルネットワークモデル

### CNN（畳み込みニューラルネットワーク）

**「畳み込み」とは？**
「畳む（折りたたむ）」のではなく、数学的な演算の名前。
画像の小さな領域にフィルター（検出器）を**スライドさせながら当てて**、特徴を抜き出す操作のこと。
例：「エッジ検出フィルター」を画像全体にスライドさせると、輪郭だけが浮かび上がる。
→ これを「畳み込む」と呼ぶ。
ハンカチをパタン、パタンと折りたたむと、面積が小さくなって厚み（情報の濃さ）が増すというイメージから来ている。輪郭を出すために、nxnのフィルターを当てて、探している線があったら、「n^2マスの画像データ」が「1マスの『輪郭があったぞ』という証拠」に変わっています。 9つのバラバラな情報が、1つの意味ある情報にギュッと小さくまとまる、これが「凝縮」の意味です


* **画像認識・画像処理**において非常に効果的なモデル

* 層を重ねるごとに認識できる特徴が複雑になる：

  * 1層目：線や色の情報

  * 2層目：形状

  * 3層目：物体・風景などの複雑な特徴

### VAE（変分自己符号化器）

- 「Variational Autoencoder」の略

**VAEが「結局何をしているか」をストーリーで理解：**

```
【目的】
「データの本質的な特徴だけを抜き出した地図（潜在空間）を作ること」
そしてその地図から「新しいデータを自由に生成できるようにすること」

【流れ】
①  エンコーダ：データを「本質だけの地図座標（潜在ベクトル）」に圧縮する
   例：犬の写真1万枚 → 「耳の形・毛の色・体の大きさ」などの数値に要約

② デコーダ：地図座標から画像を復元する
   例：「耳：垂れ耳、毛：茶色、体：大」の数値 → ゴールデンレトリバーの画像

【ここが重要：「で、何に使うの？」】
地図（潜在空間）を手に入れると、こんなことができる：

・「耳：垂れ耳 → 立て耳」に変えると新しい犬の画像が生成できる
・地図上で「見たことのない座標」を指定すると存在しない新しい画像を生成できる
・「この画像は地図のどこにも当てはまらない」 → 異常検知に使える
```

**VAEの用途まとめ：**

| 用途 | 仕組み |
|------|------|
| **新しいデータ生成** | 潜在空間上の任意の座標からデコーダで新しい画像・データを生成する |
| **次元削減** | 大量の特徴を少数の本質的な数値（潜在ベクトル）に圧縮して扱いやすくする |
| **異常検知** | 正常なデータは潜在空間に収まるが、異常なデータは再現誤差が大きくなることで検出できる |
| **データの特徴学習** | 「何が似ていて何が違うか」の構造をAIが自動的に把握できる |

### GAN（敵対的生成ネットワーク）

**GANをストーリーで理解する：**

```
【登場人物】
  生成器（偽造師）：本物そっくりの偽札を作ろうとする
  識別器（鑑定士）：本物か偽物かを見破ろうとする

【訓練の流れ】
  ① 生成器がランダムなノイズから「偽の画像」を生成
  ② 識別器が「本物のデータ」と「偽の画像」を比べて本物か偽物か判定
  ③ 生成器は「見破られた」フィードバックを受けて偽造技術を向上
  ④ 識別器は「騙された」フィードバックを受けて鑑定力を向上
  ⑤ ①〜④を繰り返すうちに生成器は本物と区別がつかないデータを生成できるようになる
```

→「敵対的」＝2つのネットワークが互いに競い合って（敵対して）学習するから

| 役割      | 内容                             |
| ------- | ------------------------------ |
| **生成器** | ランダムノイズを受け取り、本物に近いデータを生成しようとする |
| **識別器** | 生成器が作ったデータと本物のデータを区別（真偽を判断）する  |

### RNN（回帰型ニューラルネットワーク）

**「回帰」とは？（RNNの文脈）**
「回って帰る（前の出力を次の入力に戻す）」という意味。
RNNでは処理した結果を\*\*次の処理にも持ち越す（戻す）\*\*仕組みがある。
例：「私は　→　猫が　→　好きです」と単語を順番に処理するとき、
　「猫が」を処理する際に「私は」の情報も持ち越して一緒に使う＝回帰。

* 音楽のような**時間的に連続したパターンを持つデータ**に適した技術

* 課題：長い文章を扱うと途中の情報が薄れていく（**勾配消失問題**）

* → この問題への対応として**LSTM**が開発された

### LSTM（長短期記憶）

| 項目        | 内容                                     |
| --------- | -------------------------------------- |
| **登場**    | 1997年提唱、2000年代に改良                      |
| **できること** | 長い時間のシーケンスデータの依存関係を学習。RNNより長期の文脈を保持できる |
| **課題**    | 長文で精度低下／時系列処理のため並列学習に不向き／大規模データに膨大な時間  |

### RNN・LSTMとTransformerの関係（覚え方）

```
RNN　→　長い文章に弱い（勾配消失）
　　　　　　　↓ 改善
LSTM　→　マシになったが、まだ遅い・長文に限界
　　　　　　　↓ 根本的に解決
Transformer　→　RNN・LSTMを捨てて全く別の仕組みで解決
```

> **試験のポイント：** RNN・LSTMは「Transformerが登場する前の技術」。限界があったから Transformer が生まれた、という**歴史の流れ**として覚える。

## 4. Transformerモデルとその派生

### Transformerとは何が違うのか（RNN・LSTMとの比較で覚える）

| 問題         | RNN・LSTMの限界               | Transformerの解決策                   |
| ---------- | ------------------------- | --------------------------------- |
| **長文への対応** | 前から順番に処理するため、離れた単語の関係が薄れる | **セルフアテンション**で文全体を一度に見て重要な部分を直接参照 |
| **処理速度**   | 順番に処理するため並列化できない          | 順番に関係なく**全単語を同時並列処理**できる          |
| **大規模学習**  | 時間がかかりすぎる                 | 並列処理のため**大幅に短縮**                  |

**「セルフアテンション（自己注意機構）」をイメージで理解：**

文章を読むとき、人間は重要な単語を無意識に「注目（アテンション）」している。
セルフアテンションはこれをAIに再現した仕組み。

例：「**猫**は魚が好きで、**それ**は毎日食べる」
→ 「それ」が何を指すか理解するには「猫」に注目する必要がある。

```
セルフアテンションの動き：
  各単語が「自分は文中の他のどの単語と関係が強いか？」を
  全単語に対してスコア計算する。

  「それ」→「猫：90点」「魚：40点」「好き：20点」…
        ↓
  スコアが高い単語の情報を重みづけして取り込む
        ↓
  「それ＝猫のことだ」と文脈を理解できる
```

* 「自己（セルフ）」＝ 外部情報ではなく**文章自身の中**で単語同士の関係を計算するから「セルフ」

* RNNと違い、順番に読まなくても**文全体を一度に見渡して**関係を把握できる

**「アテンション層のみで構築」とは？**

RNNやCNNは「情報を順番に送る層」や「フィルターで特徴を抽出する層」が必要だった。
Transformerはそれらを**全部廃止**し、セルフアテンションの計算だけを行う「アテンション層」だけを積み重ねた構造にした。

```
RNN系モデル：[入力] → [再帰層] → [再帰層] → ... → [出力]
                        ↑順番に処理・並列化不可

Transformer：[入力] → [アテンション層] → [アテンション層] → ... → [出力]
                        ↑全単語を同時処理・並列化可能
```

→ アテンション層だけに絞ることで「並列処理ができる＝高速・大規模学習に対応」を実現した。

**Transformerの特徴まとめ（試験で出やすい）：**

* CNN・RNNを**使わない**

* **アテンション層のみ**で構築（→並列処理が可能になる理由）

* データの順番に関わらず**同時並列処理**

* 大規模データの学習時間を**大幅に短縮**

### Transformer以降の派生モデル

| モデル         | 開発元         | 時期       | 特徴                                                         |
| ----------- | ----------- | -------- | ---------------------------------------------------------- |
| **GPT**     | OpenAI      | 2018年6月  | 大量テキストデータを学習して新しい文章を生成するAI。Transformerがベース                 |
| **BERT**    | Google      | 2018年10月 | 自然言語処理モデル。**双方向性**が特徴（単語の前後どちらの文脈も使って意味を判断）                |
| **RoBERTa** | Facebook AI | 2019年    | BERTの改良版。BERTの**約10倍のデータ量と時間**で訓練                          |
| **ALBERT**  | Google      | -        | BERTを軽量化したモデル。**パラメータ数を大幅削減**。計算リソースが制限された環境でも高いパフォーマンスを実現 |

#### BERTの特徴：MLM（マスク言語モデル）

* ランダムに選ばれた単語をマスクして、その単語を予測

* マスクした単語の前後すべての情報を使用（→ **双方向**）

* **NSP（Next Sentence Prediction）**：ある文が別の文の直後にくるかどうかを予測し、2つの文の関連性を理解する

## 5. ChatGPTの概要

* OpenAIが開発した一連の自然言語処理モデル

* **2022年11月**に公表

* 「Chat」＝対話型 / 「G」＝Generative（生成） / 「P」＝Pre-trained（事前学習済み） / 「T」＝Transformer

## 7. ChatGPTの主な機能・拡張

### Code Interpreter（コードインタープリター）

* 2023年に実装

* ChatGPTが**Python**を使ってソースコードを自分で書いて実行する機能

* できること：データ分析 ／ グラフの作成 ／ 数学の計算 ／ ファイルの読み書き

### GPTs

* 自分のニーズに合わせてカスタマイズした**オリジナルのChatGPT**を作れる機能

* 特定の振る舞いの設定 ／ 特定のファイルの参照 ／ 外部APIとの連携が可能

* 自作のGPTを「**GPTストア**」に公開したり、他人が作ったものを利用することも可能

### マルチモーダル vs オムニモーダル

**「オムニ」とは？**
ラテン語で「すべて（All）」という意味。オムニモーダル＝すべての種類のデータを統合して扱う。

| 種類                   | 内容                                                                             |
| -------------------- | ------------------------------------------------------------------------------ |
| **マルチモーダル**          | テキスト・画像・音声など複数のデータを扱えるが、**各種類ごとに個別に処理**して応答する（画像の質問→画像担当が処理、テキストの質問→テキスト担当が処理） |
| **オムニモーダル（GPT-4o等）** | すべての種類のデータを**統合的に同時処理**する。テキスト＋画像を組み合わせて全体を踏まえた応答が可能。音声応答速度も人間の会話に近い           |

## 9. その他の主な生成AIサービス

### Gemini（Google）
- Googleが開発したAI
- **2023年12月**に初公開。以降 1.5 → 2.0 → 2.5 へと進化
- 特徴：
  - 最初からテキスト・画像・音声・動画・コードなどを**同じモデルで一体的に学習**している設計（マルチモーダルネイティブ）
  - 問題の難易度に応じて考える量を自動調整できる**リーズニング機構**を持つ
- 現在の主なモデル：**2.5 Pro**（高性能）、**2.5 Flash**（高速・軽量）、**Gemini Nano**（端末上で動作する軽量版）

### Claude（Anthropic）
- 「**Constitutional AI（コンスティテューショナルAI）**」を採用
  - あらかじめ定めた原則に基づき「**無害・役立つ・正直**」を保つ設計
- **Claude 3**（3月発表）から本格化。3種類のモデルがある：

| モデル | 特徴 |
|------|------|
| **Haiku（俳句）** | 超高速・低コスト |
| **Sonnet（ソネット）** | 速度と能力のバランス型 |
| **Opus（オーパス）** | 複雑な推論を行う最上位モデル |

- 標準で**約120万トークン**の長大なコンテキストを扱える
- テキスト・画像などの**マルチモーダル入力**に対応
- **Artifacts（アーティファクト）機能**：画像理解や文書を別ウィンドウで並行して生成・編集できる
- **Claude 4**（5月発表）：外部ツールを並列に呼び出しながら長時間タスクを遂行できる**ハイブリッド設計**を導入
- **2025年8月**：自分で段取りを立てて外部ツールを使いながら完了まで仕事をこなす**AIエージェント的タスク**や実運用のコーディング・推論の精度をさらに強化
- 提供経路：ウェブサービス（claude.ai）／API／企業向けクラウド基盤（Amazon Bedrock、Google Vertex AI）
- ※ ClaudeはOpenAIの**Codexは内包していない**

### Copilot（Microsoft）
- **Excel・Outlook・Teams**などのMicrosoft 365製品に組み込まれ、文書作成・データ整理・メール支援・会議要約まで業務を横断的に支援
- 基盤モデルに**OpenAIのGPT-5**を使用。幅広い用途に対応

| 種類 | 内容 |
