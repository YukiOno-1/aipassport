# 第5章：AIの利活用に関するルール・ガイドライン・法律

---

## 1. AIの利活用に関するルールの全体像

- AIが無秩序に利用・活用されると社会的にさまざまな問題を引き起こす可能性がある
- そのため、AIと社会の関係やAIの利活用に関するガイドラインが策定・公表されてきた

### 主な経緯

| 時期 | 内容 |
|------|------|
| **2019年3月** | 統合イノベーション戦略推進会議が**「人間中心のAI社会原則」**を内閣府から公表 |
| **2024年4月** | 生成AIの普及など近年の技術の急速な進展に対応するため、既存のガイドラインを統合・更新した**「AI事業者ガイドライン」**を経済産業省・総務省から公表 |
| **2025年3月** | AI事業者ガイドラインがバージョンアップ |

### ガイドラインの構造（ピラミッド構造）

```
         基本理念
           ↓
        AI社会原則
           ↓
      共通の指針（10項目）
           ↓
  AIガバナンスの構築（高度なAIシステムに関わる事業者向け）
```

---

## 2. 人間中心のAI社会原則：3つの基本理念

AI事業者ガイドラインでは、AIによってもたらされる**3つの価値**を基本理念としている。

| 基本理念 | キーワード | 内容 |
|------|------|------|
| **人間の尊厳が尊重される社会** | Dignity（ディグニティ） | AIを効率性追求の道具として使いつつも、人間がAIに過度に依存したりAIに行動をコントロールされる社会ではなく、人間がAIを道具として使いこなすことで創造性・やりがい・精神的・物質的に豊かな生活を送れる社会を構築する |
| **多様な背景を持つ人々が多様な幸せを追求できる社会** | Diversity & Inclusion（ダイバーシティ＆インクルージョン） | 多様な背景・価値観・考え方を持つ人々が多様な幸せを追求し、それらを柔軟に包摂した上で新たな価値を創造できる社会。AIはこの理想に近づける有力な道具となり得る |
| **持続可能な社会** | Sustainability（サステナビリティ） | AIの活用によりビジネスやソリューションを次々と創出し社会の格差を解消し、地球規模の環境問題・気候変動などにも対応可能な持続性のある社会を構築する方向へ展開させる |

---

## 3. AI社会原則の概要

### 各主体が取り組む事項
- 基本理念より導き出される「人間中心の考え方」をもとにAIシステム・サービスの開発・提供・利用を推進し、人間の尊厳を守りながら事業における価値の創造・社会課題の解決とAIの目的を実現していくことが重要
- 各主体はAI活用に伴う社会的リスクの低減を図るべく**安全性・公平性**といった価値を確保することが重要
- **プライバシー保護**・**セキュリティ確保**を行うことが重要
- **透明性の向上**・**アカウンタビリティ**（説明責任）を果たすことが重要
- バリューチェーン全体でのAI安全確保・**マルチステークホルダーでの継続的議論**が重要

### 社会と連携した取り組みが期待される事項
- AIによる社会への便益をいっそう増大させるためには、各主体それぞれの取り組みに加え、**社会と積極的に連携することが期待される**
- 社会の分断を回避し、すべての人々にAIの恩恵が行き渡るための**教育・リテラシー確保の機会を提供**することが期待される
- 新たなビジネス・サービスが創出され持続的な経済成長の維持・社会課題の解決策が提示されるよう、**公正競争の確保**および**イノベーションの推進**に貢献していくことが期待される

## 4. 共通の指針（10項目）

AIシステム・サービスを開発・提供・利用する各主体が留意すべき10個の共通指針。

| # | 指針 | 主な内容 |
|---|------|------|
| 1 | **人間中心** | すべてを前提とした上で、各主体はAIパフォーマンスを可能な範囲で高め、人々に便益および豊かさを与え幸福を実現することが期待される |
| 2 | **安全性** | 人間の生命・身体・財産・精神および環境への配慮、適正利用・適正学習 |
| 3 | **公平性** | AIモデルの各構成技術に含まれるバイアスへの配慮・人間の判断の介在。不適切なバイアスを生む要因を特定し排除することが重要。AIに単独で判断させず適切なタイミングで人間が判断を確認する |
| 4 | **プライバシー保護** | 個人情報保護法等の関連法令の遵守・プライバシーポリシーの策定・公表。社会的文脈および人間の合理的な期待を踏まえてプライバシーが尊重・保護されるよう対策を取る |
| 5 | **セキュリティ確保** | AIシステム・サービスの機密性・完全性・可用性の安全確保のため、その時点での技術水準に照らして合理的な対策を講じる |
| 6 | **透明性** | 関連するステークホルダーへの情報提供・合理的かつ誠実な対応・説明可能性・解釈可能性の向上 |
| 7 | **アカウンタビリティ** | トレーサビリティの向上・共通の指針の対応状況の説明・責任者の明確化・関係者間の責任の分配・ステークホルダーへの具体的な対応・文書化 |
| 8 | **教育・リテラシー** | AIリテラシーの確保・教育・リスキリング・ステークホルダーへのフォローアップ |
| 9 | **公正競争確保** | 各主体は新たなビジネス・サービスを創出し、持続的な経済成長の維持および社会課題の解決策を提示しAIをめぐる公正な競争環境の維持に努める |
| 10 | **イノベーション** | オープンイノベーションの推進・相互接続性・相互運用性への留意・事実の情報提供 |

## 5. 高度なAIシステムに関わる事業者共通の指針（AIガバナンス）

高度なAIシステムに関わる事業者が守るべき事項：

- **AIライフサイクル全体にわたるリスクの特定・評価・低減**
- 導入後の脆弱性・悪用されたインシデントやパターンの特定
- 高度なAIシステムの能力・限界・不適切な使用領域の公表
- **透明性確保の支援によるアカウンタビリティ向上への貢献**
- 産業界・政府・市民社会・学術界での**責任ある情報共有とインシデントの報告**
- リスクベースのアプローチに基づく**AIガバナンスとリスク管理方針の策定・実施・開示**
- AIライフサイクル全体にわたる**物理的セキュリティ・サイバーセキュリティ・内部脅威に対する安全対策など強固なセキュリティ管理の実施**
- AIが生成したコンテンツを認識できるようにする**電子透かし**などの技術・信頼できるコンテンツ検証・来歴のメカニズム開発・導入
- 社会的安全とセキュリティ上のリスクを軽減する研究と効果的な軽減策への優先的投資
- 気候・医療・教育などの世界課題に対処する高度なAIシステムの優先的開発
- 国際的な技術規格の開発・採用の推進
- **適切なデータインプット対策の実施・個人データと知的財産の保護**

## 6. AI新法（人工知能関連技術の研究開発および活用の推進に関する法律）

### 概要
- 正式名：**人工知能関連技術の研究開発及び活用の推進に関する法律**
- **2025年6月4日に公布**された**日本初のAI分野の法律**
- 目的：国民生活の向上・国民経済の発展に資するため、AIの研究開発・活用を総合的・計画的に推進すること
- **イノベーションの推進とリスク対応の両立**を図り、罰則規定を設けずに企業の自主性に重きを置く基本法

### AI新法の主な内容

| 項目 | 内容 |
|------|------|
| **AI戦略本部の設置** | 内閣にAI戦略本部を設置し、政府横断で方針を決定・実行する |
| **AI基本計画の策定** | 研究開発・人材育成・教育・施設設備・国際協調・ルール整備などを推進 |
| **各主体の責務** | 活用事業者は基本理念に沿った積極的な活用の取り組みと国・自治体の施策への協力義務が定められている（違反しても罰則はない） |

### AI新法における「人工知能関連技術」の定義
- 人工的な方法により**人間の認知・判断などを代替する機能を実現する技術**
- 機械学習・情報と人工知能管理技術を利用して処理し結果を出力する情報処理システムに関する技術
- この枠組みに**ディープラーニング・自然言語処理・画像認識・生成AIなどの主要技術が含まれる**

### 「活用事業者」の定義
- 人工知能関連技術を用いた**製品・サービスの開発・提供**をするもの
- または、これらを**事業活動に活用**するもの
- 基本理念に沿う積極的な活用・高度化への努力に加え、**国・地方公共団体の施策に協力しなければならない**（単なる努力義務を超える強い義務）

### AI新法とAI事業者ガイドラインの関係

| | AI新法 | AI事業者ガイドライン |
|---|------|------|
| **性格** | 法律（基本法） | 指針（法的拘束力なし） |
| **役割** | 国の大方針・計画・調査研究の枠組みを定め、事業者の協力義務を明確化する | 法的な強制部分はないが、AIライフサイクル全体でのリスク低減を支援する認証指針として機能 |
| **目的** | イノベーション推進とリスク対応の両立を図る | AIの安全・安心な活用を目指す実践的な指針を提供 |
