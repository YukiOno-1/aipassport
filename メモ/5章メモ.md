# 第5章：AIの利活用に関するルール・ガイドライン・法律

---

## まず全体像を掴む（5章を理解するための地図）

**5章で登場するものの関係を先に整理する：**

```
【抽象度：高】
　　AI新法（2025年）
　　└ 日本初のAI基本法。「国としてAIを推進する方針」を法律で定めた
　　　 罰則なし・大方針のみ。ピラミッドの「外枠」に相当

【抽象度：中〜低】
　　AI事業者ガイドライン（2024年〜）←ピラミッド本体
　　┌─────────────────────────────────
　　│ 頂点：基本理念（3つの価値）  ← 「めざす社会のビジョン」
　　│   ↓
　　│ 中層：AI社会原則            ← 「原則・方針」
　　│   ↓
　　│ 下層：共通の指針（10項目）   ← 「具体的にやること」
　　│   ↓
　　│ 底辺：AIガバナンス          ← 「高度AIに関わる事業者の追加義務」
　　└─────────────────────────────────
```

**「ピラミッド構造」の意味：**
抽象的な「理念・原則」が上にあり、具体的な「行動指針」が下にある。
上から下に向かって「なぜやるか → 何をやるか → どうやるか」の順で具体化される構造。

**AI新法はピラミッドのどの立ち位置？**
→ ピラミッドの「外枠（法的な根拠）」。
ピラミッドは「事業者が自主的に守るガイドライン」。AI新法は「国が法律として後押しする枠組み」。
2つは別物だが、どちらも「人間中心のAI社会」を目指す方向は同じ。

## 2. 基本理念（ピラミッドの頂点）

**試験用の覚え方：3つのキーワードと英語を押さえる**

| 基本理念 | 英語キーワード | 一言まとめ |
|------|------|------|
| **人間の尊厳が尊重される社会** | Dignity（尊厳） | 人間がAIを道具として使いこなす社会。AIに支配されない |
| **多様な幸せを追求できる社会** | Diversity & Inclusion | 多様な価値観・背景を持つ人々が共存・共創できる社会 |
| **持続可能な社会** | Sustainability（持続可能性） | 環境問題・格差解消にもAIを活かす社会 |

## 3. AI社会原則（ピラミッドの中層）

### 試験用の理解（長い内容を2行でまとめると）

> **「各主体が基本理念に向けて取り組む際の方向性」を示したもの。**
> 要は「安全性・公平性・プライバシー・セキュリティ・透明性・説明責任を確保しながらAIを使いましょう、そのためにステークホルダー全員で議論・連携しましょう」という原則。

### 各主体が取り組む事項（キーワードのみ）
- **安全性・公平性**の確保
- **プライバシー保護・セキュリティ確保**
- **透明性向上・アカウンタビリティ**（説明責任）の遂行
- バリューチェーン全体でのAI安全確保
- **マルチステークホルダー**（企業・政府・市民・学術など多様な関係者）での継続的議論

### 社会と連携した取り組みが期待される事項（キーワードのみ）
- 社会の分断を回避し**教育・リテラシー確保の機会を提供**
- **公正競争の確保**および**イノベーションの推進**への貢献

## 4. 共通の指針・10項目（ピラミッドの下層）

### 公平性が理解しづらい → こう理解する

**公平性の問題は「AIが差別的な判断をする可能性がある」こと。**

```
なぜ不公平な判断が生まれるか？

学習データに偏りがある
　例：採用AIを「過去の採用データ」で学習させると
　→ 過去に男性しか採用されていなければ「男性を優先する」AIができあがる
　→ これは人種・性別・年齢などで差別するAIになる

AIに単独で判断させると気づかないうちに差別が起きる
　→ 対策：適切なタイミングで人間が判断をチェックする
```

**公平性の指針でやること：**
- 不適切なバイアス（偏り）を生む要因を特定し排除する
- AIに単独で判断させず、**適切なタイミングで人間が介在する**
- 差別的な結果が生じていないかを分析・対処するプロセスを導入する

### アカウンタビリティとは

**「アカウント（account＝説明する）」＋「アビリティ（ability＝能力）」**
→ **「自分がやったことをきちんと説明できる責任・能力」のこと**

例：企業がAIで採用選考をした場合
　→「なぜこの人が不合格になったのか」を説明できること＝アカウンタビリティ
　→ ブラックボックスのままで「AIが決めた」では済まない

AIに関する文脈では：
- トレーサビリティの向上（どのデータで・どう学習・どう判断したかを追跡できる）
- 責任者の明確化・関係者間の責任の分配
- ステークホルダーへの具体的な対応・文書化

### オープンイノベーションとは

**「自社の壁を越えて外部と連携して新しいものを生み出す」という考え方**

```
クローズドイノベーション（従来型）：
　自社の研究開発部門だけで新技術を作る → 時間・コストがかかる

オープンイノベーション：
　大学・他企業・スタートアップ・政府などと知識・技術・アイデアを
　オープンに共有・連携して新しいものを生み出す
　→ AI分野では「モデルのオープンソース化」「産学連携」なども含まれる
```

### 10項目の一覧（試験用：キーワードで覚える）

| # | 指針 | 一言メモ |
|---|------|------|
| 1 | **人間中心** | AIは人の幸福のための道具 |

| 4 | **プライバシー保護** | 個人情報保護法遵守・ポリシー公表 |
| 5 | **セキュリティ確保** | 機密性・完全性・可用性の確保 |
| 6 | **透明性** | 説明可能・解釈可能にする |
| 7 | **アカウンタビリティ** | 追跡可能・責任の明確化・文書化 |

## 5. AIガバナンス（ピラミッドの底辺：高度AIに関わる事業者向け追加義務）

高度なAIシステムに関わる事業者が守るべき事項（キーワードのみ）：

- AIライフサイクル全体でのリスク特定・評価・低減
- 高度AIシステムの能力・限界・不適切な使用領域の**公表**
- 責任ある情報共有とインシデント報告
- リスクベースの**AIガバナンスとリスク管理方針の策定・実施・開示**
- **電子透かし**などによるAI生成コンテンツの識別技術の導入
- 個人データと知的財産の保護

## 6. AI新法（日本初のAI基本法）

| 項目 | 内容 |
|------|------|
| **正式名** | 人工知能関連技術の研究開発及び活用の推進に関する法律 |
| **公布** | **2025年6月4日**（日本初のAI分野の法律） |
| **目的** | AIの研究開発・活用を総合的・計画的に推進し、国民生活向上・国民経済発展に資すること |
| **特徴** | イノベーション推進とリスク対応の両立。**罰則なし**・企業の自主性に重きを置く基本法 |
| **主な内容** | AI戦略本部の設置（内閣）／AI基本計画の策定（研究開発・人材育成・国際協調・ルール整備等）／活用事業者の協力義務 |

### AI新法における「人工知能関連技術」の定義
- 人工的な方法により**人間の認知・判断などを代替する機能を実現する技術**
- ディープラーニング・自然言語処理・画像認識・生成AIなどが含まれる

### AI新法とAI事業者ガイドラインの違い

| | AI新法 | AI事業者ガイドライン |
|---|------|------|
| **性格** | 法律（基本法） | 指針（法的拘束力なし） |
| **ピラミッドの位置** | 外枠（法的根拠） | ピラミッド本体 |
| **役割** | 国としての大方針・事業者の協力義務を法的に明確化 | AIライフサイクル全体でのリスク低減を支援する実践指針 |
| **罰則** | なし | なし |
