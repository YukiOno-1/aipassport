# 第6章：プロンプトとLLM・プロンプティングの技術

---

## 1. プロンプトとLLM・LMの基礎

### プロンプトとは
- AIは何もしなくても勝手にテキストや画像を生成するわけではない
- ユーザーが求めることをモデルに伝えることで初めて必要なものを生成する
- この「モデルに対して指示や質問を行うインプット」を**プロンプト**という

### LM（Language Model：言語モデル）
- 自然言語からなる文章について、コンピュータがテキストの確率分布を学習するモデル
- 文章がどれだけ自然であるかを評価するモデル
- 直前の単語を与えられると、文章の中で次にくる単語を予測することができる
- 例：GPTは大量のデータセットを用いて、前の文脈から次のトークンを予測するよう訓練されたLM

### LLM（Large Language Model：大規模言語モデル）
- LMに比べて非常に大規模なデータセットで学習された言語モデル
- **10億以上〜数百億以上のパラメーター**を有し、自然言語処理タスクを高い精度で実行できる
- GPT-3・GPT-4などのモデルがLLMの代表例

### LLMで実現できる自然言語処理タスク

| タスク | 内容 |
|------|------|
| **自然言語生成** | データ・情報をもとに自然なテキストを生成する（例：レポートの自動作成） |
| **質問応答** | 特定の質問に対する回答を生成する |
| **感情分析** | テキストに含まれる感情（ポジティブ・ネガティブ等）を判定する |
| **テキスト要約** | 長い文章を短くまとめる |
| **機械翻訳** | ある言語のテキストを別の言語のテキストに自動翻訳する |
| **文書分類** | テキストを特定のカテゴリー・クラスに分類する |
| **言語モデリング** | 言語の構造やパターンを学習し、次にくる単語や文を予測する |

## 2. プレトレーニングとファインチューニング

LLMは**プレトレーニング（事前学習）**と**ファインチューニング（微調整）**の2段階で高い性能を実現している。

| 段階 | 内容 | 目的 |
|------|------|------|
| **プレトレーニング** | 大量のテキストデータを使用して自然言語の知識を学習する方法。主に**教師なし学習**が用いられる | 自然言語の基礎知識を与えること。特定のタスクには未対応の状態 |
| **ファインチューニング** | プレトレーニング済みのモデルを特定のタスク・用途に合わせた追加データで再学習させる | タスクごとの性能を向上させる。特定の表現や文体を学習させる |

## 3. 生成パラメータ（デコーディングパラメータ）

文章生成の際、次の単語の選び方を調整するための設定値。
※学習前に設定する「ハイパーパラメータ」とは別物。こちらは推論（文章生成）時に調整する値。
代表的なものにTemperature（温度）とTop-Pがある。

モデルの動作を調整するための設定値。代表的なものに**Temperature（温度）**と**Top-P**がある。

### Temperature（テンペラチャー）
- **生成されるテキストの自由度・多様性を調整するパラメーター**
- 0〜1（または0〜2）の範囲で設定される

| 設定値 | 効果 |
|------|------|
| **高い（1に近い）** | テキストの多様性が高くなり、より自由な発想・創造的で予測しにくいテキストが生成される。創作・アイデア出しに向く |
| **低い（0に近い）** | 典型的でルールに従った、予測可能なテキストが生成される。事実確認・法的文書・スケジュール作成など正確さが求められる場合に向く |

### Top-P（トップP）
- **次の単語を選ぶ際に考慮する候補の範囲を確率で制限するパラメーター**
- 0〜1の範囲で設定される

```
仕組みの例：Top-P = 0.9 と設定した場合

① 次の単語の候補を確率の高い順にリストアップする
② 確率の累積が90%に達するまでの単語だけを候補に残す
③ その絞り込んだ候補の中から次の単語を選択する

→ Top-Pを高くすると多くの候補から選ばれ多様になる
→ Top-Pを低くすると少ない候補に絞られ典型的になる
```

- 適切なTop-P設定により、意味のある新しいテキストを生成しながらも適切な語彙を使い続けることができる

## 4. プロンプティングの基礎

### プロンプティングとは
- 生成AIから望ましい回答を引き出すために、特定の形式・内容で質問・指示を設計すること
- LLMモデルへのプロンプト入力に特定の様式はなく、**質問形式・命令形式・会話形式など、どのような形式でも構わない**

### 出力品質を向上させる4つの要素

| 要素 | 内容 |
|------|------|
| **インストラクション（Instruction）** | AIに何をすべきか・どのような行動をするかを具体的に指示する部分。命令文で明確に伝える |
| **コンテキスト（Context）** | AIがタスクを実行するための背景情報・参照情報を提供するもの。文脈を与えることでより的確な回答が得られる |
| **インプットデータ（Input Data）** | AIに処理を依頼する対象の情報やデータ。このデータをもとにAIが分析・処理・出力を生成する |
| **アウトプットインジケーター（Output Indicator）** | どのような形式・構造で結果を示すかを指示する。形式・内容・方法で希望する出力を指定する |

## 5. ゼロショット・フューショットプロンプティング

### ゼロショットプロンプティング
- **「例示（ショット）なし」**でプロンプトを入力する方法。単純な質問のみで構成
- 簡単なタスクであれば信頼性の高い結果が得られる
- ただしタスクが複雑な場合は、事実と異なる内容や文脈と無関係な内容を出力する可能性があり、**信頼性が低くなる可能性がある**
- ゼロショットプロンプティングを実施した場合でも、**最終的には人間の判断で確認することが必要**

### フューショットプロンプティング（Few-Shot）
- **「ショット（例示）を2〜3個入力」**して質問を行うことで、より望ましい回答を得るプロンプティング手法
- 例示によってAIが期待する回答のパターン・形式を学習し、より精度の高い出力を得られる

## 6. テキスト生成AIのビジネス利用と不得意な作業

### ビジネスでの活用場面（例）
- メール・報告書・提案書などの文章作成
- アンケートや資料の要約
- ただし、**テキスト・文章に機密情報や個人情報が含まれないよう注意**が必要
- **意味の誤解が含まれていないか**・**人間らしい文章になっているか**を人間が確認することが必要

### テキスト生成AIが不得意な作業
AIによる生成には設計原理・学習データセット・学習方法などの観点から限界があり、以下の作業は**正確な結果を期待できない可能性がある**：

| 不得意な作業 | 理由・補足 |
|------|------|
| **新しい情報の生成** | 学習データのカットオフ（学習締め切り日）以降の情報は持っていない |
| **感情や直感に基づく判断** | AIに感情・直感はない |
| **深い文脈の理解** | 行間・ニュアンス・暗黙知の理解は苦手 |
| **正確な文字数による回答** | 文字数を厳密に制御することは難しい |
| **複雑な計算** | 高精度な数値計算・論理演算は得意ではない |
| **最新情報に関する出力** | 学習データの範囲外の情報には対応できない |
| **芸術的な表現の評価** | 美的・感性的な判断基準を持たない |
| **モラルや倫理に関する判断** | 文化・背景・文脈によって正解が変わる問題は難しい |
