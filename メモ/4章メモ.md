# 第4章：インターネットリテラシー・個人情報・知的財産権

---

## 1. インターネットリテラシーとは

- インターネットに関わるテクノロジーを理解し、適切に使用できる**知識・能力**のこと
- 「リテラシー」＝もとは「読み書き能力」を意味する英語。現在は「特定分野の知識・理解力・能力」という意味で広く使われる

### インターネットリテラシーの主な要素

| 要素 | 内容 |
|------|------|
| **テクノロジーの理解** | 時代の流れに合わせてテクノロジーを把握する能力 |
| **情報リテラシー** | 特定の情報を迅速に見つけ・判断し・活用する能力 |
| **セキュリティとプライバシー** | データのプライバシーを守る手段を知り実践する能力 |
| **デジタル市民権** | 情報を効果的に見つけ・活用・創造できる能力を持ち、他のユーザーやコンテンツに対し倫理的な視点で関わり、オンライン環境を安全・責任ある方法で活用できること |

## 2. セキュリティとプライバシー保護

### 主なリスクと脅威

### フィッシング詐欺
- メール・Webサイトを通じて、詐欺師が**正規の機関やサービス提供者を装い**、個人情報・金融情報を不正に収集しようとする詐欺

### QRコード
- 「Quick Response Code」の略。スキャンするだけで関連付けられたURLに自動誘導されるコード
- 非常に便利だが、**偽のQRコード**（悪意のあるサイトへ誘導）の場合、詐欺被害につながる可能性がある

### Wi-Fi
- デバイス同士を無線で接続してインターネット・ネットワークにアクセスするための技術・規格
- **偽のWi-Fiに接続すると通信内容を盗聴されるリスクがある**
- 対策：Wi-Fiオフ設定・自動接続しない設定にする
- ⚠️ 自ら判断してWi-Fi接続しても安全とは限らない（偽名を名乗る偽Wi-Fiもあるため）

### アップロード・ダウンロードの危険性

| 操作 | 主なリスク |
|------|------|
| **アップロード時** | 個人情報・機密情報の流出 |
| **ダウンロード時** | **マルウェア**への感染 |

### マルウェア
- 「Malicious Software（マリシャス・ソフトウェア）」の略
- **コンピュータ利用者に被害をもたらすことを目的としたソフトウェアの総称**

**マルウェア対策：**
- アンチウイルスソフトを常に最新状態に保ち、定期的にシステムスキャンを実行する
- ダウンロード前にファイルの出所を確認する
- 未知のソースのファイルを開かない
- 不適切なWebサイトへのアクセスを避ける

### ランサムウェア
- マルウェアの中でも特に危険性が高いもの
- 「Ransom（身代金）＋ Software」を合わせた造語
- 感染したコンピュータ内のデータを**無断で暗号化して人質にし**、復元するための身代金を要求する
- ⚠️ 仮に身代金を払ってもデータが復元される保証はなく、さらに高額の要求をされる可能性もある

## 3. ソーシャルエンジニアリング攻撃

- **信頼・恐怖・好奇心**といった人間の心理的・感情的な隙をついて、個人情報や重要データを盗み出す手法

| 手法 | 内容 |
|------|------|
| **スピアフィッシング** | 特定の個人・組織を標的にしたフィッシング攻撃。事前に対象の情報をリサーチし、信頼できる人物になりすましてメール等でリンク・添付ファイルを送信し情報を詐取する |
| **フィッシング** | 不特定多数のユーザーを対象とした詐欺 |
| **ベイト攻撃** | 魅力的なソフトウェアや注目コンテンツを「餌」としてターゲットの興味を引き、情報を取得したりマルウェアをダウンロードさせる行為 |
| **ブラックメール** | 個人・組織に対して秘密や情報を公開することで脅迫し、金銭を要求する行為 |
| **プリテキスティング** | 特定の目的を達成するために虚偽の情報・状況を利用してターゲットを騙す行為。攻撃者はターゲットの信頼を得るために信頼性の高いシナリオを設定し、それを根拠に情報を要求する |

## 4. プライバシー設定

- 他のユーザーや企業が自分の個人情報にどの程度アクセスできるかを設定すること
- プライバシー設定をせずにインターネット・アプリを利用していると、**知らぬ間にプライベート情報が閲覧・収集される**可能性がある

## 5. 個人情報保護法

### 目的・経緯
- 正式名：**個人情報の保護に関する法律**
- 社会の情報化の進展に伴い個人情報の利用が拡大することを考慮し、**個人情報の有用性に配慮しつつ個人の権利・利益を保護すること**を目的とする

### 施行・改正の主な経緯

| 年 | 内容 |
|------|------|
| **2005年** | 個人情報保護法の全面施行 |
| **2016年** | 個人情報保護委員会の設置（内閣府の外局） |
| **2017年** | 個人情報取扱事業者の範囲拡大：従来は5,000人以下を取り扱う事業者は対象外だったが、**取り扱う個人情報の数にかかわらず**、個人情報データベース等を事業用に使用しているものは個人情報取扱事業者に該当するよう変更 |

### 個人情報の定義

生存する個人に関する情報で、次のいずれかに該当するもの：
1. **氏名・生年月日その他の記述等により特定の個人を識別できるもの**（他の情報と容易に照合でき、それにより個人を識別できるものを含む）
   - 例：生年月日・電話番号・住所・家族構成・年齢・学籍番号・メールアドレス・防犯カメラの記録等
2. **個人識別符号が含まれるもの**
   - 例：顔認証・指紋情報・DNAデータ・免許番号・住民票コード・マイナンバー・基礎年金番号等

### 要配慮個人情報
- 個人情報の中でも特に取り扱いに配慮が必要な情報
- 本人の**人種・信条・社会的身分・病歴・犯罪歴・犯罪被害事実**など
- 取得・利用・提供には**事前に本人の同意が必要**
- 要配慮情報を含む個人データが漏洩した場合は**個人情報保護委員会への報告が必要**

### 匿名加工情報
- 特定の個人を識別できないように個人情報を加工し、元の個人情報を復元できないようにした情報
- 匿名加工情報を扱う事業者の義務：
  - 個人を特定できないよう適切に加工する義務
  - 加工方法等の安全管理措置を講じる義務
  - 情報中の個人に関する項目を**公表する義務**
  - 第三者提供する場合は提供情報の項目・方法を公表し、匿名加工情報であることを明示する義務
  - 自ら利用する場合は本人を識別する目的での他情報との照合を禁止

### 個人情報データベース
- 個人情報を含む情報の集合物で、次のいずれかに該当するもの：
  - コンピューターで特定の個人情報を**検索できるように体系化**した構成のもの
  - 50音順等の一定の規則に従って整理・分類され検索できるもの（コンピューター入力なしの紙のリストでも該当）

### センシティブ情報（機微情報）
- 金融分野における個人情報保護ガイドラインで定義
- 内容：政治的見解・宗教・労働組合・人種・民族・健康状態・性生活または性的指向・刑事処分の事実など
- 個人プライバシーや人権に重大な影響を与える恐れがあるため、**要配慮個人情報を含む機微情報**として位置づけられている

### 生成AIと個人情報保護
生成AIに学習データセットやプロンプトを入力する際は、個人情報保護法に基づき以下を遵守する必要がある：
- 個人情報を含むプロンプトを入力する場合、**利用目的に必要な範囲内**に留めること
- 利用目的を超えて収集した個人情報を利用する場合は**事前に本人の同意**を得ること
- 収集した個人情報は目的外使用や不正な提供を避けること
- 個人情報の保管・廃棄には適切なセキュリティ対策を講じること

## 6. 知的財産権の基本

- **知的財産権**＝創作物・発明・商標・デザインなど人間の知的活動によって生み出された財産的価値のあるものについて、創作者・発案者などに与えられる法的な権利の総称

### 主な知的財産権の種類

| 権利 | 内容 | 手続き | 存続期間 |
|------|------|------|------|
| **著作権** | 著作物を創作した著作者に与えられる権利。著作物の使用・複製・配布・展示・演奏に関する独占的な権利 | **登録不要**（創作した時点で自動発生） | 個人：死後70年 ／ 法人等：公表後70年 |
| **特許権** | 発明の保護と利用を図るための権利。対象となる発明の実施を独占できる。侵害者への差し止め・損害賠償請求が可能 | **手続き必要** | 出願日から**20年** |
| **意匠権** | 物品・建築物・画像の形・模様といった**デザインを保護**するための権利。侵害者への差し止め・損害賠償請求が可能 | **手続き必要** | 出願日から最長**25年** |
| **商標権** | 事業者が自社の商品・サービスを他社と区別するために使用する識別マークを保護するための権利。侵害者への差し止め・損害賠償請求が可能 | **手続き必要** | 登録日から**10年**（更新可能） |

### 肖像権
- 自分の顔・姿などの肖像について、**他人に無断で使用・公表されない権利**
- 個人のプライバシー保護を目的とする
- 法律上の明文規定はないが、**日本国憲法第13条（幸福追求権）**に基づいて保護される権利とされている

### パブリシティ権
- 著名人がその名前・肖像などから得られる**経済的価値を排他的に利用する権利**
- 芸能人・スポーツ選手などが有する顧客吸引力を、他人が許可なく商業的に利用することはできない

## 7. AI生成物と知的財産権

### AI生成物と著作権（文化庁、2025年2月見解）

| ケース | 著作権の扱い |
|------|------|
| 人がAIを**道具として使用**し、創作意図・創作的行為が認められる場合 | **著作物に該当**。AI利用者が著作者となる |
| 人が何ら指示を与えず**生成ボタンを押すだけ**で生成したもの | 著作物に**該当しない** |

**著作権が発生する可能性が高いケース：**
- 人が創作した著作物を生成AIを利用して発展させた新たな著作物
- 生成AIが生成した著作物を人が発展させたもの

### AI生成物と特許権（特許庁、2025年2月見解）

- 発明者は「発明の技術的特徴部分の具体化に**創作的に関与した者**」とされる
- AIを利用した発明でも、人が学習用データの選択・学習済みモデルへの指示等で創作的に関与していれば、**その発明は人のもの**
- 人が創作的に関与していない純粋なAIによる発明は、現在の日本では**人の発明として認められず、特許の取得が認められない可能性が高い**

**特許権が発生する可能性が高いケース：**
- 人が発明を生成AIを利用して発展させた新たな発明
- 生成AIが生成した発明を人が発展させたもの

### AI生成物と意匠権
- 意匠も発明と同様の考え方を採用
- AIを利用した新製品の意匠についても、人が一定程度創作的に関与している場合は**人の意匠**となる

**意匠権が発生する可能性が高いケース：**
- 人が創作した意匠を生成AIを利用して発展させた新たな意匠
- 生成AIが生成した意匠を人が発展させたもの

### AI生成物と商標権
- 商標権は創作よりも**使用**が重視される制度
- 生成AIが生成した商標であっても、人が生み出した商標と同じく**商標権の保護対象となる**

### AI生成物と肖像権・パブリシティ権
- 生成AIが作成した画像に**実在する人物の顔・姿**が含まれる場合、内容・表現の仕方によっては**肖像権が発生する可能性**がある
- 生成AIが実在する人物の**声**を生成した場合にも肖像権が発生する可能性がある
- 生成AIが生成した商品広告等に著名人の肖像・氏名が含まれる場合、次のような使用は**パブリシティ権が発生する可能性**がある：
  - 肖像・氏名それ自体を独立して鑑賞対象となる商品として使用する場合
  - 商品の差別化を図る目的で肖像・氏名を商品に付する場合
  - 肖像・氏名を商品等の広告として使用する場合

## 8. 不正競争防止法

### 目的
- 事業者間の**公正な競争**を確保し、不正競争の防止および不正競争に関わる損害賠償に関する措置を講じ、**国民経済の健全な発展に寄与すること**を目的とした法律

### 主な不正競争行為

| 類型 | 内容 |
|------|------|
| **周知な商品等表示の混同行為** | 他人の商品・営業表示として需要者の間で広く認識されているものと同一または類似の表示を使用して、他人の商品や営業と混同させる行為 |
| **著名な商品等表示の希釈化行為** | 他人の著名な商品・営業表示と同一または類似のものを自己の商品・営業表示として使用する行為 |
| **商品形態の模倣行為** | 他人の商品を模倣した商品の譲渡を行う行為 |
| **営業秘密に関わる不正行為** | 営業秘密を不正な方法で取得し、使用または開示する行為 |
| **限定提供データに関わる不正行為** | 限定提供データを不正に取得し、使用または開示する行為 |
| **技術的制限手段に関わる不正行為** | 営業所で用いられている技術的障壁を不正に回避・突破する装置などを提供する行為 |

### 営業秘密の3要件
営業秘密として保護されるには以下の3つをすべて満たす必要がある：

| 要件 | 内容 |
|------|------|
| **秘密管理性** | 秘密として管理されていること |
| **有用性** | 事業活動に有用な技術上または営業上の情報であること |
| **非公知性** | 公然と知られていないこと |

### 限定提供データの3要件

| 要件 | 内容 |
|------|------|
| **業として提供** | 特定のものに対してデータを反復継続的に提供すること |
| **電磁的方法により相当量蓄積** | 電磁的方法で相当量を蓄積されることで利活用の可能性等の価値を有すること |
| **電磁的方法により管理** | 特定のもの以外の第三者がアクセスできないよう電磁的管理を行っていること |

### AI生成物と不正競争防止法

**営業秘密の保護：**
- 営業秘密は人が生み出したものに限定されていないため、生成AIの生成物であっても**3要件を満たせば営業秘密として保護される**

**AI生成物の利用と違反リスク：**
- 他社が保有する**営業秘密を生成AIに入力**し、その生成物を利用することは**不正競争防止法違反となる可能性**がある
- 防止策：
  - 生成AIに営業秘密を入力しない
  - 誤って入力してしまった場合、該当するAI生成物を利用しない
